Provider server

The client's backend. It calls the gateway with OAuth client credentials (POST /oauth/token); the gateway calls it back through a connection, which can use OAuth client credentials too.

Timeouts, mTLS and authentication for calls to the provider server. Choose OAuth 2.0 client credentials on the connection to have the gateway fetch a token.
Receives <%= isIssuer ? 'offer and issuance events' : 'the verified claims' %> as JSON, signed in X-Wallet-Signature (HMAC-SHA256 of "t.body" with the callback secret). Retried after 5 s, 30 s, 2 min, 10 min and 1 h.
